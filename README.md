# Air, Actually

A static Singapore haze dashboard using NEA data. It shows what the current reading means for outdoor activity, exercise, masks and windows.

Live site: https://richmondgoh8.github.io/haze-guide-sg/

## Start developing

Use Node.js 24 (`.node-version`) and npm.

```sh
npm ci
npm run dev
```

Open http://127.0.0.1:5173. Source changes reload automatically. Edit `src/` and `public/`; `dist/` is generated by `npm run build`.

Read [the architecture guide](docs/ARCHITECTURE.md) for the data flow and [the contributor guide](CONTRIBUTING.md) for common changes, tests and deployment. The browser app uses native JavaScript modules and has no runtime package dependencies. Vite, Playwright and Prettier are development tools.

## What it shows

- NEA's **1-hour PM2.5 concentration** (µg/m³) for North, South, East, West and Central, with NEA's four official bands. This is the measure to use for immediate outdoor activities.
- NEA's **24-hour PSI** for the selected region. This is a different measure and is useful for the broader picture; the site does not invent or convert it into a one-hour “AQI.”
- Plain-language activity advice following the [NEA personal guide](https://www.haze.gov.sg/resources/1-hr-pm2.5-readings), including guidance for vulnerable people.
- A short mask guide based on the [Ministry of Health haze guidance](https://www.moh.gov.sg/others/haze/).
- East is the default region on a first visit. An explicitly chosen region is remembered on that browser.
- The region selector includes town examples from NEA's published region guide. These are reporting regions, not a street-level air-quality estimate.
- A next-hour outdoor activity recommendation, with separate everyday activity, strenuous exercise, mask and higher-risk guidance. Unavailable, stale and invalid timestamps withhold the recommendation.
- A mobile-friendly comparison of cloth, surgical/KF-AD, N95, KN95, KF94 and FFP2 masks, plus KF80, N99/FFP3/KF99, N100/P100, reusable and valved options. The ratings describe laboratory filtration, not guaranteed personal protection.
- A four-step haze scale, with the current level marked in text and colour. The scale uses NEA's existing bands; it is not a separate risk score.
- Both reading cards use readable sans-serif numbers and their own labelled colour scales: four PM2.5 bands and five PSI categories. Their colours follow each measurement independently; stale values lose their current marker and card tint. These UI colours are not a new health index.

## Window advice

NEA recommends closing windows when outdoor air worsens and reopening them periodically when it improves. It does not publish a one-hour PM2.5 threshold for opening windows.

The window card is an editorial rule, not an official cutoff: at 56 µg/m³ or above it suggests limiting smoke entry while planning ventilation; in the 0–55 band it suggests considering airing if outdoor air has improved. It does not tell users to keep a room sealed all day or assume outdoor air is cleaner than indoor air.

The guide explains heat, CO₂, recirculating air-con and particle filtration. For persistent haze without adequate cooling, it recommends a cooler indoor place where possible. If windows must be opened to cool the home, it advises closing them once comfortable and filtering particles if a purifier is available. The heat exception follows EPA smoke-and-heat guidance; Singapore's PM2.5 bands and activity rules remain from NEA/MOH. There is no fixed ventilation timer or indoor-air estimate.

Sources: [NEA household FAQ](https://www.nea.gov.sg/our-services/pollution-control/air-pollution/faqs), [NEA indoor-air guidance](https://www.haze.gov.sg/docs/default-source/faq/detailed-practical-tips-for-manging-iaq-during-haze.pdf), [EPA smoke and heat advice](https://www.epa.gov/wildfires/reduce-your-smoke-exposure), [EPA on passive air exchange](https://www.epa.gov/emergencies-iaq/power-outages-and-indoor-air-quality-iaq).

## Mask comparison and value guidance

Filtration and fit information comes from [HSA](https://www.hsa.gov.sg/announcements/guide-to-masks-and-respirators/), [NIOSH](https://www.cdc.gov/niosh/ppe/respirators/ffr.html), [3M's standards comparison](https://multimedia.3m.com/mws/media/1791500O/comparison-ffp2-kn95-n95-filtering-facepiece-respirator-classes-tb.pdf), [MFDS](https://www.mfds.go.kr/webzine/202002/sub05.html), and [HSE's FFP3 comparison](https://www.hse.gov.uk/research/assets/docs/personal-protective-equipment-selection-for-healthcare-settings.pdf).

The cost guidance is editorial: compare price per mask after testing fit, buy genuine products, and avoid unnecessary premium features. It does not quote live retail prices or assume that one certification is always cheaper. Activity and mask guidance was reviewed on 17 October 2026.

## Mobile and search

The page has responsive reading cards, navigation and mask comparisons, readable mobile body text, and expandable mask-rating and safe-use details. A single mask infographic combines a fit illustration, four rating rows and concise care/value notes. The homepage has one live window card; the full ventilation explanation lives on its dedicated guide page. There is no repeated tips section. Activity-specific mask advice remains with the current reading. Guide links sit in a compact footer. Core guidance is in the HTML so it remains readable without JavaScript; live readings require JavaScript. The observed 24-hour PSI is labelled separately from NEA's forecast for future activities.

Guides lead with labelled icons, short activity verdicts, mask-rating cards and placement diagrams. Longer explanations use native disclosures; heat, higher-risk and filtration caveats stay visible. There are no autoplay effects or additional health scores. This follows cognitive-accessibility principles, not a claim of clinical ADHD suitability.

`tooling/icons.js` renders the shared SVG icons at build time from `<!-- icon: name -->` markers. Add a named path there and use a visible text label beside it. Shared infographic layouts live in `src/styles/components/visual-guide.css`; thresholds and activity copy remain in the existing domain/content modules.

The dashboard and three dedicated guides have unique titles, descriptions, canonical URLs, sharing metadata and static HTML. `tooling/site-pages.js` drives the build entries, metadata, related-guide links and generated sitemap at `/haze-guide-sg/sitemap.xml`. Guide pages also have breadcrumb structured data and do not load the dashboard JavaScript.

The shared section bar stays at the top while scrolling and includes a Top link. Native links work without JavaScript; scroll offsets keep targets below the bar at phone widths and enlarged text. Region preferences use local storage, not cookies. The official advisory and forecast link sits beside the readings, separate from this project's practical advice.

The [SEO guide](docs/SEO.md) covers Search Console setup, ranking priorities, measurement and GitHub Pages limitations. These changes prepare pages for discovery; they do not guarantee search rankings or submit the site to Search Console. GitHub project sites do not control the domain-root `robots.txt`; no project-level robots file is used as a substitute.

## Sources and accuracy

A scheduled GitHub Action fetches the public [PM2.5 API](https://api-open.data.gov.sg/v2/real-time/api/pm25) and [PSI API](https://api-open.data.gov.sg/v2/real-time/api/psi), validates them, and publishes `/haze-guide-sg/data/latest.json` with the site. Browsers request that same-site snapshot; visitor traffic cannot trigger government API calls. Both datasets are supplied by NEA: [PM2.5 dataset](https://data.gov.sg/datasets/d_e1058d6974c877257e32048ab128ad83/view), [PSI dataset](https://data.gov.sg/datasets/d_fe37906a0182569d891506e815e819b7/view). The page displays the original source timestamps in Singapore time. If data is missing or more than two hours old, it withholds reading-specific activity advice and band-position context.

The schedule runs at minutes 7, 22, 37 and 52, avoiding the start-of-hour rush. GitHub can delay or drop scheduled runs, and public-repository schedules can be disabled after 60 days without repository activity. CDN caching and deployment time add latency too. This is not an exact 15-minute freshness guarantee. Monitor Actions and the displayed source timestamps; use the official site when current advice is unavailable.

`tooling/publish-snapshot.js` retains the latest validated published measurement per feed when a source fails or returns an older timestamp. It never changes the source timestamp to the collection time. If neither live nor previous data is usable, publication fails and the existing deployment stays up. Local builds contain an explicitly empty snapshot: run `node tooling/publish-snapshot.js` after building if you need real data in a local production preview. Never commit live readings.

Band-position context shows distance to adjacent NEA bands, not a trend, forecast or safety margin. For example, 140 is 11 µg/m³ below High, which starts at 151, and 85 above the Normal ceiling of 55. The highest band is open-ended, so it has no artificial meter maximum.

This is an independent project and is not an official government website. Readings cover five broad regions, not individual streets or indoor air.

## Checks and production preview

```sh
npm test                    # Rules, API normalization, preferences, controller and HTML assembly
npx playwright install chromium
npm run test:e2e             # Builds the site and checks it in Chromium
npm run format:check
npm run build
npm run preview             # http://127.0.0.1:4173
```

If Chromium is already installed locally, `CHROMIUM_PATH=/path/to/chromium npm run test:e2e` uses that executable. The standard Playwright install works across supported development platforms.

## Deployment

GitHub Pages serves the generated `dist/` directory. Pushes to `main`, manual runs and the 15-minute schedule run the existing verification and security gates before deployment. Browser tests use fixtures and do not depend on NEA availability. The publication step then collects the real snapshot; a failed collection uses validated prior readings or stops deployment if none exist. Scan artifacts are retained for one day to limit storage from scheduled runs. Standard hosted runner execution is free for public repositories; this does not promise unlimited storage or permanent free-tier terms.

The free URL is `https://richmondgoh8.github.io/haze-guide-sg/`. Relative build asset paths also support GitHub project URLs. A custom domain can be added later in the repository's Pages settings.

## Privacy and security

See [SECURITY.md](SECURITY.md) for browser protections, repeatable scans, disclosure and hosting limits, and the [security assessment](docs/SECURITY-ASSESSMENT.md) for results and open findings. Automated scan success is not a certified VAPT pass.

There are no API credentials to expose. The browser only requests a public, same-site JSON snapshot. GitHub Actions uses its normal deployment permissions; no new account or external secret is needed. Scheduled collection bounds upstream requests independently of visitor traffic, but is not per-IP rate limiting or a DDoS guarantee. The only locally stored value is the selected region. The site has no analytics, account system, or user data collection.
